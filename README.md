# RyoGeese

由手电加鞭制作的魔兽世界视觉技能推荐软件。

自有源码采用 **GPL-3.0-only**；自有 GPU 读取器另有使用 NVIDIA／微软运行库的附加许可。第三方组件保留原许可，见 [LICENSE](LICENSE) 与 [许可范围](LICENSING.md)。

RyoGeese 读取独立 Dash 插件显示的游戏信息，在本地计算并显示一个技能建议。当前支持暗牧、虚空编织者、BOSS 单体；其他职业尚未实现。

- [软件固定下载页](https://github.com/muttsf/RyoGeese/releases)
- [独立 Dash 插件仓库](https://github.com/muttsf/RyoGeese-Dash)
- 当前用户版本：`0.1.0-beta.4` 候选。

## 使用流程

1. 单独安装并启用 Dash，保持插件面板完整可见。
2. 打开软件，导入当前角色的完整 SIMC 导出。
3. 定位插件，打开技能按键设置；按键可按需要填写或留空。
4. 确认后开始推荐。需要移动插件时，重新定位。

软件根据导入的职业、天赋和装备选择内置已支持模板。循环由维护者更新、验证并随软件版本发布；玩家无需导入循环文件。软件不执行 SIMC 中的自定义动作或 `include` 指令。

## 图标与音效

首版不附带游戏技能图标和网络音频片段。缺少图标时，技能名称和按键仍正常显示。

主页面“导入图标包”直接选择ZIP，一个包可以包含所有职业，按技能编号自动匹配。
更新时整包替换；缺少图标的技能留空，失败保留旧包。图片只存本机，规则见
[ICON_IMPORT.txt](ICON_IMPORT.txt)。图标包通用不代表尚未实现的职业循环已可用。

技能按键可以留空；点过第三步“技能定位”即可进入第四步，没填的技能显示“鼠标点击”。
正常使用双击软件文件夹里的“点我启动.exe”。它只启动程序，不是安装器。

## 支持范围

- 已实机使用：Windows 11、NVIDIA RTX 5080。
- NVIDIA RTX 30 系及以上为理论兼容目标，其他型号没有逐一实测；AMD CPU 不受品牌限制，AMD 显卡暂不支持。
- 支持角色资料版本为 12.1.5、TOC 120105、90 级；天赋资料基线是 12.1.5.70391。同补丁不同小构建号仍须通过天赋等检查，不代表自动适配新热修。
- 目前只支持已明确适配的暗牧天赋范围；召唤物分支等未支持条件会明确拒绝。
- 8GB 内存紧张的情形没有实机兼容保证。驱动和微软 Visual C++ x64 运行库需满足说明。

程序按 500 毫秒安排取图，识别串行执行，决策逐份完成，推荐窗保留最近收到的结果。没有下一招预测，也不监控玩家按键。移动、受控和引导状态不另行切换推荐算法。实际间隔会受到系统调度和处理耗时影响。

## 数据与卸载

退出主窗口和推荐窗后再更新或卸载。用户数据独立于安装目录，卸载有意保留：

- SIMC 与按键：`%LOCALAPPDATA%\AiHekili\startup\current.json`，保留旧路径以兼容已有记录。
- 报错及推荐日志：`%LOCALAPPDATA%\RyoGeese\logs`。
- 自选图标：`%LOCALAPPDATA%\RyoGeese\icons`。

日志按卷轮换并清理已关闭旧卷，约 200MiB 为清理目标；系统拒绝清理时不会为控制大小阻塞推荐。反馈日志前请检查个人信息。

软件安装器不包含、不安装、不覆盖游戏插件。插件设置由游戏单独保存。

## 源码、依赖与维护

- `app/`：桌面层、内置循环、参考配置、模型和视觉监督源码。
- `native/`：独立 GPU 读取器的 C#、CUDA 源码和 NuGet 锁。
- [BUILDING_PORTABLE.txt](BUILDING_PORTABLE.txt)：离线依赖准备、通用组装及 NSIS 构建步骤。
- [MAINTENANCE.txt](MAINTENANCE.txt)：由维护者检查补丁和 SIMC、验证及发布循环的流程。
- `DEPENDENCIES.json`：程序外部运行依赖的逐文件校验值。

构建需要事先提供与清单匹配的运行依赖目录；当前没有实现自动从上游下载依赖的一键构建。各第三方组件保留各自许可，详见 `app/notices/`。每个版本的安装器和完整对应源码一起发布；更新前请先退出软件。安装器暂未作数字签名。

## 异常处理与签名

定位失败按原流程等待下一轮；GPU分配、帧复制和推理的未恢复异常会记录并结束本次读取。不保证所有异常自动恢复，详见 `app/运行边界说明.txt`。当前安装候选未作Authenticode签名；制作人资源字段不是证书身份，不要求关闭系统防护。
